# Security Policy

## Purpose

This repository contains technical interview challenges for Database Reliability Engineer candidates. It does not contain production code, sensitive data, or credentials.

## Reporting Security Issues

If you discover a security concern related to this repository (e.g., accidentally committed credentials, PII exposure), please report it privately:

- **Email**: security@letsgetchecked.com
- **Do NOT** open a public GitHub issue for security concerns

## Scope

This repository is intentionally public and contains:
- Challenge instructions and scenarios
- Sample SQL scripts with intentional issues (for candidates to identify and fix)
- Datadog monitor templates with intentional issues

It does **not** contain:
- Production credentials or connection strings
- Patient data or PII
- Answer keys or evaluation rubrics
- Internal system documentation

## Candidate Note

If you are a candidate completing this challenge and believe you've found sensitive information that shouldn't be public, please notify your recruiter immediately.
