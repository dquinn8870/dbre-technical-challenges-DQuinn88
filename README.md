# DBRE Technical Challenges

Technical assessments for Database Reliability Engineer candidates — migration, monitoring, and operational scenarios.

## Structure

| Folder | Level | Status |
|--------|-------|--------|
| [`senior/`](senior/) | Senior DBA / DBRE | Available |
| `junior/` | Junior DBA | Coming soon |

## For Candidates

Navigate to the challenge folder matching your interview level. Each contains:

- A detailed README with instructions and time expectations
- Reference materials in `schema/`, `monitoring/`, or `incidents/`
- A `submissions/` folder for your answers

Read the README in your assigned folder carefully before starting.

## For Interviewers

Interviewer materials (answer keys, scorecards, defense questions) are maintained separately and not included in this public repository.
